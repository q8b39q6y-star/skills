# 公众号内容工作台 (gzh-workflow)

> **Umbrella skill** — covers the full WeChat 公众号 content pipeline:
> ① 每日选题推荐 (daily topics) ② 文章生成 (generator) ③ 文章审核 (audit)
> All three phases share the same "十大元素" framework.

完整工作流：

```
cron 7:00/11:00/18:00
   ↓ hot_topics.py 抓微博热搜
~/.hermes/data/weibo_hot/latest.json
   ↓ 本 skill 的"每日选题"模块
10 个候选选题
   ↓ 用户选择
"文章生成"模块产出 5 段式正文
   ↓ "文章审核"模块对照十大元素逐项打分 → 修改建议
推送发布
```

加载本 skill 后，按用户意图自动选择对应模块即可——同一份框架的不同入口。

> **通用写作技巧**：本 skill 负责公众号特有的十大元素框架与 5 段式结构。需要中文语感、语气拿捏、去 AI 味、朗读检验等通用写作工艺时，配合 `creative-writing` skill 使用。需要给选题做背景调研时用 `research-workbench`；需要把视频/播客内容转成选题素材时用 `media-utilities`。

## 模块 1：文章生成（基础模块 — 十大元素框架 + 5 段式结构）

## 触发条件
- 用户说"帮我写一篇公众号"
- 用户说"生成推文"
- 用户提供一个热点话题
- 用户指定某个内容方向（如"AI科普"、"易经科普"等）

## 内容方向库（已验证可写）

### 热点+玄学类
- 韩国AI国民分红 ✅
- 其他时事热点（随时可追加）

### 易经/玄学科普系列
- 《易经是不是迷信》✅ 开篇
- 十二生肖年度运势（待写）
- 风水实用技巧（待写）
- 奇门遁甲入门系列（待写）

### AI原理科普系列
- 《AI的脑子能装多少字》（上下文窗口）✅
- Token生成原理（待写）
- AI幻觉真相（待写）
- RAG vs Fine-tuning决策指南（待写）
- Embedding：AI怎么理解词的意思（待写）
- 思维链CoT：AI怎么做推理（待写）

### 哲学/深度类
- 《真正的人工智能是全人类牺牲自己的神性造出来的神》✅
- 《财运本质是"用认知和行动兑现概率"》✅

---

## 输入信息
生成文章前必须收集：
1. **热点话题**（事件名称+核心人物）
2. **争议焦点**（为什么会上热搜）
3. **情感锚点**（亲情/爱情/友情选哪个切入）
4. **目标读者**（职场人/宝妈/学生/粉丝等）

---

## 文章结构模板

### 标题公式
```
情绪词 + 主体 + 事件 + 反转/悬念
示例：《XX翻车，我终于读懂了什么叫"XX"》
示例：《那个最XX的人，怎么就塌房了》
```

### 开头公式（前300字）
- 冲突性场景还原（一句话抓住注意力）
- 一句有杀伤力的引语（当事人说过的话）
- "破碎感"画面描写（情绪共鸣）

### 正文公式（5段式）

**段落1：人物背景**（建立信任/共情）
- 介绍核心人物，语气亲近，不要百度百科腔
- 关联读者的情感记忆

**段落2：事件还原**（提供信息增量）
- 讲清楚发生了什么
- 加入时间线、数字、细节

**段落3：争议焦点**（情绪引爆点）
- 撕开问题的本质
- 用反问句制造张力
- 至少覆盖2种情绪（愤怒+怀旧、愤怒+愧疚等）

**段落4：深层追问**（引发思考）
- 从个案延展到普遍现象
- 追问"为什么会这样"
- 提出一个让人想评论的观点

**段落5：收尾表态**（引发共鸣）
- 一句金句升华
- 开放式讨论邀请
- 不要假大空的鸡汤

|---------|---------|---------|

## 禁止清单
- 不要机械罗列事实，要有人情味
- 不要用"据悉""有消息称"等冷冰冰的表达
- 不要在结尾说"大家怎么看"这种废话，用具体问题替代
- 不要标题党，内容要配得上标题

## 使用示例

**用户输入：**
> 帮我写一篇关于"监狱来的妈妈"电影争议的公众号文章，目标读者是职场人，从愤怒+怀旧切入

**AI执行：**

5. 输出完整文章

## 模块 2：文章审核（对照六大维度逐项打分 → 修改建议）

### 使用场景
- 写完一篇公众号文章后，对照检查
- 发现文章"太空"时逐项诊断
- 投稿前自检是否达标

### 爆款审核 — 六大维度

#### 一、标题公式
```
情绪词 + 主体 + 事件 + 反转/悬念
```
- [ ] 是否有情绪词（扎心、暴击、真相、悄悄…）
- [ ] 是否有明确主体（豆包、离火运、打工人…）
- [ ] 是否有悬念/反转钩子
- [ ] 字数是否在 20-30 字之间

#### 二、开头公式（前 300 字）
- [ ] 是否有冲突性场景（一个人/一件事的具体状态）
- [ ] 是否有一句有杀伤力的引语（当事人说过的话）
- [ ] 是否有"破碎感"画面描写
- [ ] 能否让人停下来（读完前 3 行不想滑走）

#### 三、正文结构（5 段式）
- [ ] 段落 1：人物背景（建立信任/共情）— 有具体人名、身份、经历
- [ ] 段落 2：事件还原（提供信息增量）— 有时间线、数字、细节
- [ ] 段落 3：争议焦点（情绪引爆点）— 撕开问题本质，覆盖 ≥2 种情绪
- [ ] 段落 4：深层追问（引发思考）— 从个案延展到普遍现象
- [ ] 段落 5：收尾表态（引发共鸣）— 金句升华，开放式讨论

#### 四、金句密度
- [ ] 每个段落是否有可单独传播的金句
- [ ] 结尾是否有让人想截图收藏的金句
- [ ] 金句是否朗朗上口（短句为主，对仗为佳）

**金句检查清单：**
```
□ 文章中有 _____ 句可独立传播的金句
□ 金句 1："________________"（适合朋友圈转发）
□ 金句 2："________________"
□ 金句 3："________________"
□ 结尾金句："________________"
```

#### 五、十大元素核查表

| 类别 | 元素 | 要求 | 检查 |
|------|------|------|------|
| **情感** | 亲情/爱情/友情 | ≥1 | □ |
| **情绪** | 愤怒/怀旧/愧疚/暖心/孤独 | ≥2 | □□ |
| **因素** | 地域细节（节目名/城市/场景） | 有 | □ |
| **因素** | 群体代入感（读者能代入） | 有 | □ |

**情感映射参考：**
- 名人翻车 → 愤怒 + 怀旧
- 亲情纠纷 → 愧疚 + 暖心
- 爱情背叛 → 愤怒 + 孤独
- 社会不公 → 愤怒 + 孤独
- 时代变迁 → 怀旧 + 希望

#### 六、禁止清单（审核版 — 区别于生成版的红线）
- [ ] 没有"据悉""有消息称"等冷冰冰的表达
- [ ] 没有"大家怎么看"的废话结尾
- [ ] 没有机械罗列事实（每个事实要有情绪附着）
- [ ] 没有标题党（内容要配得上标题）

### 审核流程

**步骤 1：读标题** — 是否符合标题公式？是否引发点击欲望？
**步骤 2：读开头** — 前 300 字是否让人停下来？没有就重写开头
**步骤 3：数人物** — 文章里有几个具体人物？（少于 2 个 → 加案例）
**步骤 4：数金句** — 全文有几句可传播金句？（少于 3 句 → 加强）；结尾有没有金句？
**步骤 5：十大元素核查** — 情感 ≥1，情绪 ≥2，地域细节，群体代入感
**步骤 6：输出结论**

### 审核结论格式（输出模板）

```
=== 爆款审核报告 ===

【标题】__________
得分：____/20  优/良/差

【开头】__________
得分：____/20  优/良/差

【人物密度】__________
得分：____/20  优/良/差  （要求 ≥2 个具体人物）

【金句密度】__________
得分：____/20  优/良/差  （要求 ≥3 句可独立传播）

【十大元素】__________
情感：□  情绪：□□  地域：□  群体：□

【禁止项检查】__________
无"据悉" □  无"大家怎么看" □  无标题党 □

【综合评分】____/100

【主要问题】__________
1.
2.
3.

【修改建议】__________
1. 开头加一个具体人物/场景
2. 第三段加一句传播金句
3. 结尾换一个有共鸣的金句
```

### 使用示例

**用户输入：**
> 帮我审核这篇公众号文章 [粘贴文章内容]

**AI 执行：**
1. 读取文章
2. 逐项检查六个维度
3. 填写审核报告
4. 给出具体修改建议
5. 提供修改后的片段示范

## 模块 3：每日选题推荐（基于微博热搜 → 10 个爆款候选）

### 触发条件
- 定时任务每天早（7 点）、中（11 点）、晚（18 点）自动运行
- 用户说"给我推荐选题" / "今天有什么可以写的"

### 数据来源（2026 年 6 月实测）

| 平台 | 状态 | 说明 |
|------|------|------|
| **微博热搜** ✅ | `https://weibo.com/ajax/side/hotSearch` | 主力数据源，无需认证；抓取脚本：`scripts/hot_topics.py` |
| 百度热搜 ❌ | JS 渲染 | cURL 无法获取，可用 `browser_navigate` 配合提取 |
| 知乎热榜 ❌ | 需登录 | 返回 403，暂不可用 |

**自动抓取：**
```bash
python3 scripts/hot_topics.py                    # 抓取并写盘到 ~/.hermes/data/weibo_hot/
python3 scripts/hot_topics.py --limit 15         # 只抓 15 条
python3 scripts/hot_topics.py --json             # 直接输出 JSON，不写盘
```
完整脚本使用文档与数据存储路径见 `scripts/hot_topics.py` 顶部 docstring。

### 选题筛选标准

**必选条件（至少满足 2 个）：**
1. 有情绪张力（愤怒/怀旧/孤独/愧疚/暖心）
2. 有时间节点（当下正在发生）
3. 有群体共鸣（打工人/宝妈/考生/创业者）
4. 有信息差（大部分人还不知道）

**加分条件：**
- 可以用玄学视角解读（九紫离火运、五行、奇门）
- 可以用 AI 视角解读（生产力、职场、替代）
- 有具体人物/事件，不是抽象概念

### 输出格式

```
=== 爆款选题推荐 [日期] ===

根据今日热点监控，精选 10 个可能出爆款的选题：

🔥 [话题方向 1]
角度：______
情绪：______
适合人群：______
预估效果：______

🔥 [话题方向 2]
...

[共 10 条，每条包含：角度、情绪、适合人群、预估效果]

---

请回复数字选择你想写的方向，我来帮你生成文章。
```

### 选题分类建议

#### A 类：玄学 + 时运（优势赛道）
- 九紫离火运的深度解读
- 奇门遁甲在现代生活的应用
- 2026 年各月份的运势节点
- 生肖/星宿的年度关键提醒

#### B 类：AI + 职场（有真实体验）
- AI 工具的使用体验对比
- 职场人的 AI 替代焦虑
- 软考/技能提升的方向建议
- 某个 AI 产品的真实测评

#### C 类：情感 + 社会（高传播赛道）
- 亲情类（父母、子女、隔代关系）
- 爱情类（婚姻、分手、婚外情）
- 友情类（同学、闺蜜、职场关系）
- 地域 + 群体代入感强的社会事件

#### D 类：干货 + 认知（建立专业感）
- 某个领域的深度分析
- 一个模型/公式/方法论的讲解
- 真实经历复盘（交易、学习、创业）
- 行业趋势预测

### 部署与维护

#### Cron 定时调度（已部署）

```bash
hermes cron list                              # 查看所有定时任务
hermes cron run <job_id>                      # 手动触发一次选题推荐
hermes cron edit <job_id>                     # 修改调度/提示词
hermes cron pause / resume / remove <job_id>  # 启停与删除
hermes cron status                            # 调度器状态（需 gateway 运行中）
```

**定时配置参考：** 每天 7:00 / 11:00 / 18:00 触发一次。

完整 cron 部署实录（命令、陷阱、调试方法）见 `references/cron-deployment.md`。

#### 数据管道

```
cron tick → scripts/hot_topics.py 抓微博热搜
         → 写入 ~/.hermes/data/weibo_hot/latest.json
         → 脚本 stdout 注入 Agent prompt
         → Agent 加载本 skill 的"模块 3"生成 10 条选题
         → 推送到 Telegram（--deliver telegram）
```

**⚠️ 交付目标陷阱：** `--deliver local` 只写入 cron 自身的 session DB，不会推送到用户面前。推送必须用网关平台（telegram / discord / slack）。

#### 注意事项
- 每次推荐要有时效性标注（"今日热榜"、"本周趋势"）
- 不要推荐太泛的选题（"AI 改变生活"太虚）
- 优先推荐有具体人物/事件的方向
- 如果热点数据获取失败，返回"今日热点暂无更新，建议关注：XXX"
